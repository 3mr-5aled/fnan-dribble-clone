# 🎨 Fnan — A Dribbble Clone (Frontend Mock)

Fnan is a clean, modern Dribbble clone designed to showcase and explore creative work. Built with **Next.js**, **TypeScript**, **TailwindCSS**, and **GraphQL**, this app features a sleek UI and responsive layout, ideal for a portfolio-style experience.

> ⚠️ **Note**: Backend operations are currently **fabricated/mocked** due to the end of the Grafbase trial. All data interactions are simulated.

---

## 🚀 Tech Stack

| Tech        | Description                          |
|-------------|--------------------------------------|
| Next.js     | React framework for SSR              |
| TypeScript  | Typed JavaScript for reliability     |
| TailwindCSS | Utility-first CSS framework          |
| GraphQL     | API query language                   |
| (Grafbase)  | Used during development, now expired |
